# C16 — a postnominal part between the family name and the given name

## Standing

- Behind a family comma whose part C1 reads as postnominal, the last later comma part that is not titles and suffixes is the given part; an empty part stops the search, and every other later part stays C2's — 2026-11-03 family-suffix-given.

Open: a head C3 counts as a whole name makes the first comma a suffix comma, so C16 does not read past it and the given name stays in the suffix: `Garcia Lopez, Jr., Juan` reads given 'Garcia', family 'Lopez', suffix 'Jr., Juan', as do a connective surname (`Ortega y Gasset, Jr., John`) and a titled one (`Dr. Smith, Jr., John`). Reading those as C16 does would reverse C2's `John Smith, MD, Bart` → suffix 'MD, Bart', which needs a maintainer's call on which reading a whole name before the comma should take when a name word follows a postnominal part.

Open: an ambiguous credential-class word or a one-letter numeral in the second part (`Smith, Ma, John`, `Smith, V, John`) is read as the given name by C4's count before the third part is seen, so C16 never applies to it; reading the third part's name word as evidence that the second part is postnominal would be a new signal for C4, not a clause here.
